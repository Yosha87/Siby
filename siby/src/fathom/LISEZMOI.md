# Fathom — Syzygy tablebase probing

C library for probing Syzygy tablebases, copied as is from
https://github.com/jdart1/Fathom (see `VERSION`).

- License: **MIT** (file `LICENSE`), compatible with the GPL of SCID vs. PC.
- Authors: Ronald de Man (Syzygy), basil00, Jon Dart.

Used by `src/syzygy.cpp` (Tcl command `sc_syzygy`) for Siby's endgame
tablebase window.
